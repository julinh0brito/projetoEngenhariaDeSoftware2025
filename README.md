A implementação foi realizada em linguagem Java, adotando princípios de programação orientada a objetos (POO) para modelar as entidades, atributos e relacionamentos descritos. 
Utilizamos coleções em memória (como ArrayList) para simular os relacionamentos, com potencial integração a um banco de dados Oracle Apex via JDBC em futuras expansões.
As classes incluem construtores, getters, setters e métodos para gerenciar relacionamentos e restrições (ex.: apenas matrículas ativas permitem adicionar provas). 
Adicionalmente, implementamos uma classe de aplicação (CtrlPrograma) para instanciar objetos e demonstrar fluxos como cadastro, matrícula e lançamento de notas.
